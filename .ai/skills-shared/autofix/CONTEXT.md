# Autofix terms

## Reported Issue

One concern from a review that the operator can decide and Autofix can address. A reported issue may be invalid and skipped.

## GitHub Source

An inline pull request comment fetched from GitHub. One comment produces one reported issue.

## Local Source

A review copied from another agent. One local source may contain several reported issues and unrelated prose.

## Project Path

The canonical root of the Git checkout where a reported issue belongs and work occurs.

## Clipboard Snapshot

The complete clipboard text captured before local issues are extracted.
