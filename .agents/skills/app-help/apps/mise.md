# mise

## Machine scope

- Oma

## Local sources

- `mise --help`
- `mise help <command>`
- `mise outdated`
- `mise which <tool>`

## Local configs

- `~/.config/mise/config.toml`
- `~/.omadots/bin/pi_update`

## Official sources

- Documentation: `https://mise.jdx.dev/`
- Upstream repository: `https://github.com/jdx/mise`

## Local gotchas

- Oma installs Pi through Mise's Aqua backend, so Pi cannot self-update that installation. Use `pi_update` to upgrade Pi through Mise and update Pi extensions.
